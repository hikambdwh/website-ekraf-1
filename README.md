# Landing Page Ekonomi Kreatif Purwakarta

### 📌 Deskripsi
Landing Page ini dibuat sebagai halaman utama untuk memperkenalkan produk, layanan, atau personal brand. Fokus utama landing page ini adalah tampilan yang menarik, responsif, dan user-friendly untuk meningkatkan engagement dan konversi pengunjung.

Landing page cocok digunakan untuk:
- Promosi produk 
- Personal portfolio
- Campaign marketing
- Informasi layanan atau aplikasi

### 🎯 Fitur Utama
- Desain modern dan responsif (mobile & desktop)
- Navigasi sederhana dan intuitif
- Call To Action (CTA) yang jelas
